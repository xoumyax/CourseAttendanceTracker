📚 Student Guide

🆕 First Time? Start Here!

1 Get Your Enrollment Code

Your instructor gives each student a one-time enrollment code (it looks like K7Q2-9MXD). You need it to create your account. Each code works once.

Keep it private. Anyone with your student ID and your code could register as you.
2 Register Your Account
  • Go to the Registration Page
  • Enter your student ID and your enrollment code
  • Choose a password (at least 8 characters)
  • Click Register, then log in
Go to Registration →

📝 Marking Attendance

3 Get the Check-in Code in Class

Your instructor shows a 6-digit check-in code during class.

  • The code is only valid for minutes

4 Check In
  • Log in and open the Mark Attendance page
  • Pick today's session and type the 6-digit code
  • Click Submit Attendance

You can check in once per session. Too many wrong codes in a row will block you for a minute.

    ❓ Common Issues
    "That student ID and enrollment code do not match"
    → Check both for typos. If the code was already used, ask for a new one.
    "Invalid or expired check-in code"
    → Check-in codes expire quickly. Ask for the current code.
    "Check-in is closed"
    → Check-in is only open during the times listed above.
    "Too many failed attempts"
    → Wait a minute, then try again.
