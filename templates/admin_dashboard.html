📖 Admin Guide

Quick reference for managing the attendance system

🎯 Quick Start

  1. Roster and codes: import students and generate enrollment codes with the CLI (see the README) or the Enrollment Codes card; hand each student their code
  2. Sessions: add a session for each class date, or create test sessions to try things out
  3. Check-in code: in class, select today's session and generate a code; show it to students
  4. Export: download the Excel report any time

⚙️ Settings for this course

  • Check-in times:
  • Check-in codes expire after: minutes (test sessions: hours)
  • Test sessions are not graded and ignore the time window
  • Disable Time Restrictions lets students check in at any time; turn it back on afterwards
  • These come from the server's .env file (see the README)

📊 Grades

    • Only regular sessions that have already taken place (today or earlier) count; the sidebar and the Excel export show live percentages up to today
    • Students not registered yet are shown in gray

    🔑 Enrollment codes and password resets

    • A student registers with their student ID plus a one-time code
    • To reset a password, press Reissue code on that student in the sidebar and give them the new code
    • Codes are shown once; download the CSV immediately

    ⚠️ Important Notes

    • Students can check in once per session
    • Too many wrong codes from one student or IP blocks them for a minute
    • The dashboard refreshes every 30 seconds
    • Roster files and code CSVs are student records: never commit or share them
